# Первый запуск · Indicators & Work

Для нового пользователя · клиент 0.1.22, сервер 1.23.0 · 24.10.2026.

Это инструкция полного дашборда со своим сервером. Для отдельного таймера с нормативами без сервера используй **[Focus & Norms](../FOCUS-README.md)** — доступны Windows и Android.

## Что попробовать сначала

Начни с двух работ и дневных нормативов. Например:

- **Чтение — 0/1:** одна помидорка каждый день.
- **Мой проект — 0/2:** две помидорки каждый день.

Затем можно освоить заметки, проекты и показатели. Для первого прохода хватит таймера и чек-листа.

В клиенте **0.1.35** можно начать без плана: в таймере нажми **Начать без норматива**, затем используй **Пауза / Продолжить / Учесть**. Карточку и норматив создавать не обязательно. Через **Новую активность** можно задать название и параметры; существующую работу запускай из её карточки. Полная свободная помидорка входит в общий дневной факт и лимит, не выполняя чужую норму.

## 1. Запуск на Windows

1. Открой [выпуск 0.1.22](https://github.com/malikvalikhodjaev/work-productivity-tool/releases/tag/v1.23.0-native-beta.24), скачай **Indicators-Work-0.1.22-windows-x64.zip** и архив **Source code (zip)**.
2. Распакуй исходники в постоянную папку, а всю папку клиента — отдельно. Установи Node.js 24. Из папки исходников открой PowerShell и выполни `node server.mjs`; оставь сервер работающим.
3. Запусти `indicators_work.exe` из распакованной папки клиента. Адрес по умолчанию — `http://localhost:8787`.
4. Дождись первой синхронизации. Проверить её можно в **Данные → Синхронизация**; доступна кнопка **Синхронизировать**.
5. Если появится **«Вы поставили нормативы на день?»**, нажми **Поставить норматив**. Это переход к следующему шагу инструкции.

В пакете нет личного архива автора. Создаются твои собственные записи; стартовые категории часовых показателей можно позднее настроить под себя. Папка приложения хранит серверный `data/`, а клиент сохраняет SQLite в системной папке пользователя.

`windows-x64.zip` содержит клиент; сервер берётся из исходников по [README](../README.md#разработка). Для первого знакомства только с таймером проще отдельный [Focus & Norms](../FOCUS-README.md), которому сервер не нужен.

**Если программа уже была установлена:** сначала сохрани тексты и выйди из неё через меню трея. Чужой адрес сервера или ошибка «другая установка» требуют проверки; очищать базу ради запуска не нужно.

## 2. Создай две отдельные нормы

1. Открой **⚙ Настройки**. В блоке **Помидорки на сегодня** нажми **＋**. Этот же чек-лист есть в показателях и плеере.
2. Нажми **Создать работу / кейс**, выбери **Работа**, введи **Чтение**, сохрани карточку.
3. В форме норматива выбери сегодняшнюю дату в **Действует с**, оставь название **Чтение**, поставь **1** в **Помидорок за день**, сохрани.
4. Снова нажми **＋**, создай **другую карточку** — **Мой проект**, поставь ей норму **2**.
5. В чек-листе должны остаться обе строки: **Чтение — 0/1** и **Мой проект — 0/2**.

Нормы повторяются ежедневно без срока окончания. На другой день факт снова начнётся с нуля; вчерашние результаты остаются в недельной истории. Для правки строки используй карандаш. Пустое количество при правке снимает норму с выбранной даты. Две строки с отдельными счётчиками связываются с двумя разными работами.

## 3. Проверь первую помидорку

1. В **Работе → Настройки таймера** поставь рабочую помидорку **1 минута** для короткого пробного прохода. Оставь режим **Помидорка** и общий таймер. После проверки можно вернуть 25 или 50 минут.
2. Нажми **▶** у строки **Чтение**. Таймер должен сразу запуститься с этим названием.
3. Нажми **Пауза**, подожди несколько секунд, затем **Продолжить**. Время паузы исключается из работы.
4. Дождись окончания. Нажми **Учесть**, если окно наблюдений ещё не открылось автоматически.
5. В **«Как прошла помидорка?»** проверь минуты. Можно описать сделанное, изменённую систему и её характеристику несколькими абзацами или оставить поле пустым. Подтверди сохранение.
6. Проверь: **Чтение — 1/1**, **Мой проект — 0/2**. Затем в **Данных → Синхронизация** дождись отправки очереди.

Досрочное завершение сохраняет реальные минуты, но не даёт целую помидорку. Сигнал окончания сам по себе ещё не означает, что результат учтён.

## 4. Пользуйся только таймером, если пока достаточно его

В блоке таймера нажми **Крупный таймер**. Откроется плеер с названием работы и дневным чек-листом. **Все разделы** возвращает к остальным экранам.

В Windows при сворачивании активного таймера появится компактное окно. Настройка **Таймер при сворачивании** находится в ⚙. Закрытие окна может оставить приложение в трее; полный выход — через меню трея.

## 5. Попробуй остальные разделы

| Хочу сделать | Куда зайти | Минимальный результат |
| --- | --- | --- |
| Записать мысль | **Письмо → Новая запись** | Название, текст, сохранить, открыть снова. |
| Сфокусироваться на проблеме | **Работа → Главная проблема** | Записать разрыв между желаемым и текущим; сохранить и найти связанный кейс. |
| Начать проект | **Проекты** | Создать проект и одну альфу: типовое имя, проектное имя, текущее представление, следующий шаг. |
| Следить за целью | **Показатели** | Выбрать показатель, понять единицу и период, записать фактическое значение. |
| Проверить сохранение | **Данные** | Найти очередь, последнюю связь, путь к SQLite и кнопку локальной выгрузки. |

## Android

Текущий APK предназначен для **arm64, Android 8.0 и новее**. Фоновое поведение конкретного телефона нужно проверить отдельно.

1. Установи **Indicators-Work-0.1.22-android-arm64.apk** из того же выпуска.
2. Подключи Tailscale к своей сети устройств. Нужен собственный сервер с настроенным закрытым HTTPS-адресом; инструкция его настройки — [computer-server.md](computer-server.md).
3. В приложении открой **⚙ → Сервер и разрешения**, введи свой HTTPS-адрес и сохрани. Нажми синхронизацию.
4. После первого подключения проверь те же работы и нормы, что на своём ПК.
5. Для сигналов разреши уведомления. Для малого окна открой **Малое окно таймера → Разрешить показ поверх приложений**.

APK сохраняет изменения без связи после первоначального подключения. Полностью автономная первоначальная настройка Android без сервера в этом выпуске ещё не реализована. У каждого пробующего должна быть своя установка: аккаунт автора и его адрес для знакомства не используются.
