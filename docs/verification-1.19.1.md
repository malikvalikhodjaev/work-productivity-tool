# Проверка 1.19.1 / native 0.1.16

Дата: 2026-10-19.

- Целевая серверная проверка: 18 тестов `pomodoro-plans` и `native-commands`, все прошли. Новые сценарии проверяют запрет замены при добавлении, конфликт с унаследованной ежедневной нормой, отдельные нормы и счётчики разных работ, сохранность файла после отказа, повтор UUID и перезапуск. Предыдущая версия 1.19.0 прошла 132 серверных теста.
- Flutter: анализ без замечаний; 74 теста прошли. Добавлены проверки создания работы и кейса из формы без сети, отмены с сохранением полей, двух строк чек-листа и запрета случайной замены. Предыдущие проверки доски, WBS, шаблонов и локальной очереди включены.
- В браузере рабочего сервера проверены две отдельные нормы в общем боксе и настройках. «+» открывает форму добавления без автоматически выбранной работы.
- Восстановление данных владельца выполнено после резервной копии через API с ожидаемыми версиями. Прежняя норма ИТ снова видна; новая норма руководств связана с отдельной работой. Исторические правила и сеансы не переименованы и не перенесены.
- Веб-сервер обновлён до 1.19.1; идентификаторы серверного сеанса таймера и архива письма сохранились. Windows 0.1.15 перед этим был установлен по подтверждению владельца; локальная SQLite и очередь сохранены. Доставка исправления 0.1.16 подтверждается отдельно по версии установленного пакета и runtime клиента.

Сборка и автоматические тесты не заменяют проверку пользователем полного сценария на телефоне: добавить новую работу с нормой, запустить её таймер и сверить отдельный факт после учёта.
