# ADR-019 · Постоянные ежедневные нормы помидорок

Дата: 2026-10-16. Статус: принято по просьбе владельца.

Владелец ожидал, что однажды заданные нормы действуют без срока окончания, и попросил сохранить их до ручного изменения или снятия. Это заменяет правило ADR-014 о необходимости ежедневно задавать новый план.

## Решение

- Новые нормы **ежедневные**. В форме поле **«Действует с»**, заголовок **«Ежедневный норматив помидорок»**. Норма повторяется с этой даты без ограничения срока, пока владелец её не изменит или не снимет. Число помидорок остаётся конечным дневным ориентиром, например 10.
- Исходные строки `pomodoroTargets` сохраняют дату начала, точное название, workRef, target и `repeat: daily`. Старые строки без repeat остаются историческими планами на одну дату; API поддерживает явный once для совместимости. В текущем интерфейсе новые записи ежедневные.
- Для выбранного дня берётся последняя применимая строка каждой работы: daily с датой начала не позже дня либо историческая строка точно на день. target:null прекращает соответствующую норму; более старый ежедневный план после снятия не возвращается.
- Правка или снятие сохраняет строку с новой датой действия и прежние версии. Изменение сегодня не переписывает план вчера. Не создаются бесконечные копии строк: дневной чек-лист и неделя рассчитываются по правилам при чтении.
- Факт каждый день начинается с 0 и увеличивается только от полных завершённых рабочих помидорок этого дня по Asia/Tashkent. Вчерашние помидорки, Leisure, паузы и ручные галочки не переносятся в новый день. Недельная статистика показывает действующий для каждого дня план; будущие дни отражают текущие правила.
- Без связи Flutter и Android-служба вычисляют тот же ежедневный план из сохранённых правил. Малое окно, настройки и напоминания используют общие правила. Сохранённая норма прекращает вопрос о необходимости поставить план и на следующих днях; часовое напоминание о невыполненном остаётся.
- По явному запросу владельца действующие старые нормы переводятся в ежедневные **с сегодняшнего дня** с прежними названиями и количеством. Исходники и факты сохраняются; перед переносом создаётся резервная копия. Снятые нормы не восстанавливаются.

## Проверка

Серверные проверки `tests/pomodoro-plans.test.mjs`: новый день, годы вперёд, перезапуск, ежедневный сброс факта, точное имя, снятие, правки с даты, совместимость исторических планов и отсутствие повторных строк. Нативные проверки `native-app/test/recurring_pomodoro_test.dart`: те же правила в локальном снимке и очереди, отсутствие вопроса при действующей норме.

[RP01–RP04](acceptance/27-recurring-pomodoro-targets.feature) заменяют прежний PN06 о новом плане каждый день. Доставка фоновых напоминаний на реальном телефоне по-прежнему зависит от системных разрешений.
