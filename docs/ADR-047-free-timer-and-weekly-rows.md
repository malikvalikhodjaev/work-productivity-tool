# ADR-047: Свободный таймер и недельный контекст в строках

Дата: 2026-10-26. Основание: запрос владельца. Клиент 0.1.35+37, сервер 1.27.0.

## Контекст аналитики

В таблице «Аналитика работы» после «Проблемы дня» находится «Проблема недели». Каждая из семи строк показывает формулировку выбранной недели, включая локальную неподтверждённую правку. Повторение намеренное: контекст остаётся рядом с днём. Отдельный повтор над таблицей убран. При переходе по неделям меняется источник; отсутствующая запись не заменяется формулировкой текущей недели. Исходные строки с пробелами и абзацами не переписываются; текст повторяется только в представлении.

## Запуск вне норматива

План помидорок не является обязательным условием учёта времени. Из карточки работы можно запустить таймер и без дневного плана. В свободном таймере есть явная кнопка «Начать без норматива»: один запуск без большой формы и создания карточки. «Новая активность» позволяет задать название, типы времени и другие параметры.

Свободный запуск использует сохранённые режим и длительность, название «Активность без норматива», пустые `workRef` и `metricId`, `allocation: outside`, неизвестный тип времени. Не создаётся фиктивный норматив, работа или категория Productive/Waste. Действие сначала сохраняется на устройстве тем же механизмом команд. Пауза, продолжение и учёт относятся к одному ID. Повторные нажатия не создают второй таймер. Другая активная работа, перерыв или помидорка, ожидающая учёта, не заменяются.

Полная завершённая рабочая помидорка без `workRef` учитывается в общем дневном факте, составе времени и личном лимите. Она не выполняет норматив другой работы. Укороченный сеанс, секундомер и перерыв не создают полную рабочую помидорку. Факты вычисляются из исходных сеансов с дедупликацией по ID и датой завершения UTC+5; исходные сеансы, планы и часы не переписываются. В API поле `workRef` такого факта равно `null`.

## Проверки

Строки выбранной и предыдущей недели, отсутствие подстановки при пропуске, точный многострочный локальный текст. Свободный запуск офлайн, неизменяемая очередь, повторное нажатие, пауза/продолжение одного сеанса, сохранность другой работы. Полное и частичное завершение, отсутствие ложного выполнения чужого плана, клиентский и серверный подсчёт. Кнопки проверяются в широком окне и на Android с читаемым текстом.
