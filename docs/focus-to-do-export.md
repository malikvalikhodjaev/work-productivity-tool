# Выгрузка Focus To-Do

Скрипты исследовательские, отдельно от запуска дашборда. Они проверялись на одном локальном снимке Windows-версии; формат после обновления приложения может измениться. Автоматического обмена с дашбордом пока нет.

## Где хранится база

Для исследованной установки Microsoft Store:

```text
%LOCALAPPDATA%\Packages\52299SuperElement.119436511DDC8_792yctbvabkar\LocalState\EBWebView\Default\IndexedDB\file__0.indexeddb.leveldb
```

Это Chromium IndexedDB поверх LevelDB: бинарный формат, а не текст с неверной кодировкой. Китайские символы в строках сохраняются при декодировании и выгрузке в Unicode.

Заверши приложение и скопируй каталог целиком в отдельную папку, чтобы файлы снимка не менялись во время чтения. Парсер получает путь к копии. Оригинальную базу не редактируй. Сырые снимки, JSONL, Excel и журналы оставляй в исключённых из Git каталогах `data/`, `outputs/`, `logs/`.

## Извлечение JSONL

`scripts/extract_focus_todo_indexeddb.py` использует Python и модуль `ccl_chromium_reader` с его зависимостями, которые должны быть заранее установлены в выбранном окружении. Парсер не входит в этот репозиторий. Скрипт принимает ровно два позиционных аргумента: каталог копии LevelDB и каталог вывода.

Пример запуска из корня репозитория для подготовленной копии `data/focus-snapshot`:

```sh
python scripts/extract_focus_todo_indexeddb.py data/focus-snapshot outputs/focus-decoded
```

Выбираются последние версии ключей; удалённые записи исключаются. Результат — JSONL по хранилищам и сводка. Имена файлов содержат номер базы и имя хранилища. Помимо задач и сеансов база может содержать сведения об участниках: результат остаётся локальным.

## Excel

`scripts/build_focus_todo_workbook.mjs` принимает каталог JSONL и путь XLSX. Скрипт использует `@oai/artifact-tool` из среды генерации документов Codex; эта зависимость не требуется дашборду и не устанавливается командой `npm start`.

В окружении, где пакет доступен Node.js:

```sh
node scripts/build_focus_todo_workbook.mjs outputs/focus-decoded outputs/focus-to-do.xlsx
```

Текущий конвертер ожидает `db2_Project.jsonl`, `db2_Task.jsonl`, `db2_Subtask.jsonl` и `db2_Pomodoro.jsonl`. Если номер базы отличается, сначала проверь результат извлечения и соответствие хранилищ. Длинные заметки разбиваются на колонки, чтобы не потерять текст из-за ограничения длины ячейки Excel. При проверке сверяй число строк, связи задач и сумму длительностей; неизвестные коды состояний сохраняются без догадок.

## Дополнительные диагностические файлы

- `scripts/inspect_focus_dump.py` — исследование промежуточного дампа; ожидает подготовленный файл во временном каталоге. Для основного извлечения не нужен.
- `docs/focus-to-do-console-export.js` — эксперимент для консоли самого приложения. Имя базы `PomodoroDB` зафиксировано в коде; оно может отличаться в установленной версии. Это не команда для консоли дашборда и не подтверждённый способ автоматизации текущей Windows-версии.

Выгрузка данных не запускает таймер. Связь с карточками Coda и правила учёта времени описаны в [ADR-001](ADR-001-time-sources.md).
