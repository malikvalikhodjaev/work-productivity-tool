# ADR-025 · Таблица проектов и рабочий моделер

Дата: 2026-10-18. Запрос: довести моделер до MVP, первым показывать таблицу проектов, затем проверить цикл на продаже дома.

## Рабочий цикл

Проекты → таблица → выбранный проект → альфа → запись и состояние → подтверждение → следующий шаг и дата возврата → история. Можно создать корневую альфу в зоне или подальфу конкретного объекта, а также запустить фокус на её workRef. Создание новой карточки не означает подтверждения состояния.

Таблица первой показывает название и состояние проекта, заполненные/созданные слоты, зоны с пробелами и объекты к возврату. В веб-версии также остаётся счётчик задач до эксплуатации. Регулярный обзор на нативном экране раскрывается отдельно. Характеристики систем, прежние проекты и альфы сохраняются.

Нативные подсказки о зонах пересчитываются по текущим карточкам, включая локальную очередь: заполнение, подтверждённое состояние, критерий, свидетельство и состояние подальф. Подтверждённый родитель с непроработанной подальфой не закрывает зону. Окончательная серверная проверка остаётся в portfolioView.

Полнота относительно обязательного шаблона не выводится из количества уже созданных объектов. Шаблон пока не выбран: этот показатель — No Data. Это не реализация запланированных M07–M08.

История загружается из существующего закрытого API /api/alphas/history по выбранному объекту и сохраняется на устройстве с привязкой к адресу сервера и ID. Без связи доступна ранее загруженная история. Ожидающие отправки правки помечаются отдельно; прежние серверные версии не подменяются ими.

## Свободные наблюдения

По замечанию владельца убраны «одной строкой» и предписание каждый раз кратко отчитываться о прорыве. Наблюдения необязательны, ввод многострочный. Клиент, общий таймер и офлайн-импорт сохраняют переводы строк и пробелы без обрезки; технический максимум — 10000 символов. Прежние записи не мигрируют и не переписываются. Изменение заменяет ограничение одной строки из ADR-010.

Проверенный сдвиг от применения руководств остаётся самостоятельным результатом; часы чтения и применения сохраняются отдельными нормами. Отсутствие прорыва не блокирует заметку или учёт времени.
