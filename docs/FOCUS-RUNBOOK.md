# Focus & Norms · Runbook

Версия 0.1.0 · 20.10.2026. [Короткий README](../FOCUS-README.md).

## Каждый день

Посмотри **Помидорки на сегодня**, нажми Play выбранной работы. Используй паузу при отвлечении. После конца подтверди минуты через **Учесть**, при желании запиши наблюдения. В недельной таблице проверь выполнение норм; в истории — сеансы и минуты.

Норма задаётся один раз и повторяется ежедневно. Карандаш меняет существующую строку. Для снятия оставь количество пустым и сохрани с нужной даты. Для второго независимого счётчика выбери другую работу или создай новую.

Если активна другая работа, открой её таймер, учти или отмени, затем запускай новую. Пауза сохраняет текущий занятый сеанс. Вклад и результат не записываются сами из-за нажатия Play другой работы.

## Сохранение

Все записи сразу сохраняются в SQLite устройства, включая пуск, паузу, продолжение, учёт и изменения норм. Серверная очередь отсутствует. Путь к данным указан в ⚙; файл — `focus-norms.sqlite`.

На Windows закрытие окна оставляет приложение в трее. Меню трея позволяет полностью завершить приложение. При активном сеансе сворачивание показывает компактный таймер, если включена соответствующая настройка. Возврат — кнопкой **Полный вид** или через трей.

На Android служба и уведомление поддерживают отсчёт в фоне. Точный сигнал и наложение окна зависят от разрешений ОС. Перезагрузка, режим энергосбережения и принудительная остановка требуют проверки на конкретном телефоне; хранение факта и доставка сигнала — разные проверки.

## Копия и ручной перенос

1. Открой **⚙ → Выгрузить копию**. Сохрани файл отдельно от устройства.
2. На другом устройстве открой **⚙ → Восстановить из копии** и выбери JSON.
3. Подтверди замену после прочтения сообщения. Идущую сейчас работу сначала нужно учесть или отменить.
4. Проверь названия работ, нормы и последнюю историю.

До восстановления приложение сохраняет собственный предыдущий JSON. Исходный выбранный JSON также сохраняется без изменения. Путь предыдущей копии появляется в сообщении и остаётся в каталоге `exports`. Для отката выбери этот файл через то же восстановление.

Если в переносимой копии таймер работал, он восстанавливается на паузе на момент экспорта. Время после экспорта не приписывается работе. Возобнови его вручную или уточни и учти минуты.

Файл импорта ограничен **8 МиБ**. Для большего архива можно сохранить весь каталог SQLite и доработать механизм импорта под свои потребности. На Windows каталог SQLite копируй после полного выхода из приложения, включая имеющиеся WAL/SHM-файлы.

Перенос файла не объединяет параллельные изменения с двух устройств. Выбирай одну актуальную копию, пока автоматической синхронизации нет.

## Обновление

Сначала выгрузи JSON и сохрани тексты наблюдений. На Windows полностью выйди через трей и замени программную папку новой сборкой. SQLite находится отдельно и сохраняется. На Android установи новый APK с прежней подписью поверх; удаление приложения очищает его локальные данные.

Самостоятельную доработку Android подписывай своим постоянным ключом. Для обновления своего APK понадобится та же подпись. Перед переходом между сборками разных авторов сохрани JSON и проверь его восстановление в новой установке.

## Быстрый разбор неисправностей

| Что произошло | Действие |
| --- | --- |
| Норма осталась 0/1 | Дождись полного интервала и подтверди **Учесть**. Досрочный результат сохраняет минуты. |
| Снова 0/1 на следующий день | Это новый день по UTC+5; прежний факт остаётся в недельной таблице. |
| Нельзя запустить другую работу | Открой названный текущий сеанс и заверши либо отмени его. |
| Нет маленького окна Windows | Проверь **⚙ → Таймер при сворачивании**. |
| Нет наложения Android | Проверь **Малое окно таймера** и системное разрешение поверх приложений. |
| Нет сигнала | Прослушай рингтон, проверь громкость, уведомления, будильники и ограничения батареи. |
| Файл не восстанавливается | Нужен JSON Focus & Norms версии 1, до 8 МиБ. Запиши точную ошибку; текущие записи при ошибке проверки сохраняются. |
| Windows сообщает о недостающей DLL | Распакуй всю папку ZIP вместе с каталогом `data` и библиотеками программы. |

Для обратной связи: устройство, версия, шаги, ожидание, фактическое поведение. Личные тексты и всю базу отправлять не требуется.
