# ADR-043 · Одна иерархическая таблица целей

Дата: 2026-10-25. Клиент 0.1.30. Заменяет два представления целей из ADR-042 по уточнению владельца.

В «Показателях» цели показываются один раз — иерархической таблицей. Закреплённые карточки, второй список декомпозиции и выбор закреплённых индикаторов из интерфейса убраны. Сохранённые пользовательские предпочтения и сами цели не удаляются. Два основных раздела «Цели» и «Нормативы» сохраняют разный смысл: желаемые изменения и регулярные планы работы.

Столбцы: цель с WBS, единица/период, «Было», «Сейчас», «Хочу», изменение, прогресс, дата замера, срок, состояние и действия. Родительские строки выделены фоном, дочерние — вложенностью и вычисляемым WBS. Стрелки независимо сворачивают ветви; есть «Раскрыть все» и «Свернуть все». Состояние ветвей хранится на устройстве по устойчивым UUID, не меняя parentId или порядок целей. Фильтр архива не меняет состояние самих целей.

В пустых ячейках целей вместо `No Data` выводится **«Заполнить»**. Для исходного значения, ориентира, единицы и срока открываются настройки цели; для текущего значения — новый замер. В пустом вычисляемом поле открывается ввод недостающих исходных данных. Ноль остаётся явно введённым нулём; подпись не подменяет неизвестный факт и не сохраняется как значение. Процент по-прежнему рассчитывается только из определённой шкалы, его нельзя ввести вручную.

Имена и тексты переносятся на строки без многоточия и уменьшения шрифта; высота строки следует содержимому. Широкая таблица прокручивается горизонтально, весь раздел — вертикально. Существующие команды редактирования, замеров, истории и добавления подцели остаются источником записи. Правила локального сохранения, конфликтов и расчёта прогресса не меняются.

Проверки: единственное представление каждой цели; отсутствие карточек целей; независимое сворачивание вложенных уровней и сохранение выбора; стабильный WBS соседней ветви; неизменность снимков/очереди от сворачивания; действие «Заполнить» для настройки и замера; явный ноль; длинное имя и увеличенный шрифт в узком окне; доступность действий после прокрутки.
