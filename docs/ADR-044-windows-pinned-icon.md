# ADR-044: Иконка закреплённого приложения Windows

Дата: 2026-10-25. Статус: принято по запросу владельца.

## Причина

У закреплённого ярлыка не был задан IconLocation; значок брался из EXE по неизменному пути. После смены изображения Windows могла продолжать показывать прежнюю иконку из кэша.

## Решение

Установщик вызывает Repair-NativeShortcuts.ps1. Из упакованного assets/iw.ico создаётся отдельный файл с частью SHA-256 в имени. Ярлыки рабочего стола, меню «Пуск» и панели задач получают этот IconLocation. Файл проверяется по полной контрольной сумме. Новое имя появляется только при изменении самой иконки.

Меняются только существующие ярлыки, которые запускают точный установленный EXE или явно переданный launch.vbs через wscript.exe. Цель, аргументы и порядок закрепления сохраняются. Перед изменением сохраняется исходный .lnk; запись проверяется повторным чтением и откатывается при ошибке. Другие приложения и устаревшие веб-ярлыки не затрагиваются.

Оболочка получает SHChangeNotify / SHCNE_UPDATEITEM для изменённых ярлыков и EXE. Глобальный кэш иконок не удаляется, Explorer и приложение не перезапускаются. Идентификатор приложения и каталог личной базы сохраняются.

## Проверка

Сравнить SHA-256 назначенного ICO с упакованным assets/iw.ico, повторно прочитать IconLocation, цель и аргументы всех найденных ярлыков. Повторный запуск не должен менять уже исправленные файлы. Применение не открывает базу и не меняет пользовательские данные.

API: https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shchangenotify
