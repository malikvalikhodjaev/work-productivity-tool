- Сервер: 132 теста прошли, 0 ошибок. Включены новые проверки WBS, циклов, переноса ветки, конфликтов структуры, независимой копии, повторной команды, импорта/экспорта и счётчиков версий. Несвязанный незавершённый тест FPF в рабочей копии не входит в эту поставку.

Проверены SQLite после перезапуска, копия с последующими правками и переносом, уже принятый сервером снимок без дублей, порядок «перенос → правка карточки», переключение списка/доски при сохранении таблицы моделера.
- Windows: собраны release AOT и assets 0.1.15+16. Используются прежние совместимые engine/runner/plugins. Это проверка сборки, а не подтверждение пользовательского прохода в установленном приложении.

## Проход в браузере

Отдельный локальный сервер с синтетическим проектом, вне личной базы:

1. Список переключается на доску, таблица выбранного проекта остаётся ниже.
2. Сворачивание и раскрытие ветки сохраняют остальные номера WBS.
3. Перенос «Документы» под «Покупатели» переносит и потомка: 2 → 2.1 → 2.1.1.
4. «Из шаблона» показывает дату сохранённого пакета, выбор областей и число будущих строк.
5. Полный локальный пакет создаёт 112 пустых альф/подальф по 8 областям. Свидетельства, проектные имена, заполненные состояния и даты не появляются сами.
6. Карточка строки раскрывает состояния из руководства как подсказки; фактическое состояние остаётся пустым.

## Ограничения и доставка

MCP Coda в этой проверке вернул внутренние ошибки. Используется личный сохранённый пакет от 2026-09-28; свежесть по отношению к текущему документу Coda не подтверждена. Частный каталог не включается в Git или установочный архив.

Перед обновлением рабочего веб-сервера сохраняются данные и заменяемые исходники. Проверяются идентификаторы текущего таймера и архива письма. Тестовые проекты не переносятся в личную базу. Обновление нативного клиента подготовлено отдельно: установленное приложение Windows не перезапускается до подтверждения сохранения открытого текста владельцем. Android-установка и пользовательский проход этой версии на телефоне не проверены.
