# ADR-014 · Дневной план помидорок

Дата: 2026-10-15. Решение принято для версии 1.11.0 / Native 0.1.1.

## Зачем

Сделать дневной объём выбранных работ видимым: название норматива и счётчик `0/1`, `0/10`. Поддерживать внимание к выбранным работам и регулярно моделировать. Ограничитель — учёт и напоминания не должны создавать выдуманный результат или уничтожать записи.

## Решение

- План хранится в `dashboard.json`, таблица `pomodoroTargets`. Ключ — дата и `workRef`. Поля: дата, точное название пользователя, целое число помидорок, даты создания/изменения и история. Пустое число снимает норму, сохраняя версию для восстановления.
- Норма относится к выбранной дате. Можно заранее поставить норму на следующий день. Вчерашний план автоматически не становится сегодняшним.
- Факт получается из сеансов таймера, а не из ручной галочки: только завершённая полная рабочая помидорка. Секундомер, перерыв, отменённая или частичная помидорка, импорт часов и отметка «Сделано» не дают единицу. Изменение длительности помидорки сохраняется в её сеансе.
- Сеанс относится к дню его завершения, часовой пояс Asia/Tashkent. Один ID сеанса учитывается один раз. При достижении нормы значок чек-листа меняется автоматически. Факт может превышать норму.
- Норматив связан с карточкой работы/задачи/кейса. Переименование карточки не переписывает имя норматива.
- В нативной форме норматива можно сразу создать работу или кейс: тип, название и описание. Карточка сохраняется в обычную коллекцию и автоматически выбирается; её название подставляется в редактируемое название норматива. Пустой список не блокирует форму. Дата и число помидорок сохраняются при создании или отмене. Без связи создание карточки ставится в очередь перед нормативом. Если закрыть только норматив, уже сохранённая карточка остаётся в разделе «Работа».
- В приложении чек-лист виден в крупном таймере, показателях, настройках и часовом окне «Сделал это?». В вебе есть плавающий бокс, настройки через ⚙ и таблица недели в разделе «Работа».
- Без хотя бы одного норматива на сегодня показывается «Вы поставили нормативы на день?»: при входе/возврате, перед закрытием окна Windows, при выходе приложения и после смены дня. «Позже» откладывает часовое напоминание; следующий вход или выход снова проверяет план. Сохранение хотя бы одного норматива на сегодня прекращает этот вопрос. Чек-лист невыполненных норм продолжает напоминать каждый час.
- В SQLite план и завершённые помидорки сохраняются без связи с сервером. Неотправленный факт помечается; повторная отправка не увеличивает счётчик. Конфликтующие и исключённые сеансы требуют разбора и в факт не входят. Правки плана используют UUID команды и версию, зафиксированную при открытии формы.
- Недельная таблица показывает факт/план по каждой заданной дате и итог. Для даты без нормы стоит «—», а для недели без планов — No Data. Норма не домысливается из отработанного времени.

## Ограничения

Браузер контролирует текст системного предупреждения при закрытии вкладки; произвольную фразу в нём гарантировать нельзя. Внутри страницы вопрос показан полностью. Браузерный таймер без сети остаётся отдельным режимом; полноценный офлайн-чек-лист доступен в нативном клиенте.

Уведомление Android при закрытом интерфейсе использует последний сохранённый снимок плана/факта. Для получения изменений с другого устройства нужно открыть приложение и синхронизировать. Android может задерживать сигналы в режиме экономии энергии; фоновую работу и разрешения нужно проверить на реальном телефоне. Принудительное завершение процесса системой не является пользовательским выходом, на котором можно показать диалог.
