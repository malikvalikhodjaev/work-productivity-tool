# Проверка Focus & Norms 0.1.0

Дата: 20.10.2026. Отдельная редакция Windows x64 / Android arm64.

## Автоматические проверки

В Flutter прошли **26 тестов** из `focus_repository_test.dart`, `focus_home_test.dart`, `quick_focus_test.dart`, `durable_timer_test.dart`, `recurring_pomodoro_test.dart`. Финальная проверка `flutter analyze --no-pub` — **No issues found**.

Проверены:

- Первый запуск и создание работы/нормы без сервера, без ожидающей очереди.
- Два независимых норматива; точное сохранение кириллицы, китайского текста, пробелов и абзацев.
- Полная помидорка, учёт минут, сохранение после открытия базы и отсутствие дублей.
- Пауза, продолжение того же сеанса и запрет подмены другой работой.
- Снятие повторяющейся нормы с сохранением прошлого правила.
- Разделение минут по полуночи UTC+5; отменённое время не входит в итоги.
- Экспорт/восстановление, сохранение прежних данных и исходного файла; отказ при повреждённой копии и активном текущем сеансе.
- Восстановление работавшего экспортированного таймера на паузе.
- Виджеты первого норматива и немедленного Play, мобильная ширина 390 × 780 с длинным названием и паузой. Обнаруженный выход селектора звука за границу исправлен.

## Сборки и первый запуск

- Windows: release AOT для `lib/focus_main.dart`; отдельный runner собран MSVC с `IW_FOCUS_EDITION`. Метаданные EXE: Focus & Norms, 0.1.0, `focus_norms.exe`.
- Запущенный Windows-процесс отвечает, заголовок **Focus & Norms**. В собственной базе `focus-norms.sqlite` установлены `focusRuntime.ready=true`, версия 0.1.0. На первом запуске работы, нормы, история и очередь пусты. Основной дашборд продолжил работать в прежнем процессе.
- Android: Gradle release завершён успешно; подпись прошла `apksigner verify`. Проверены пакет `uz.iw.focus_norms`, версия 0.1.0 / код 1, arm64-v8a, заголовок Focus & Norms и существующий класс MainActivity в namespace исходников. В результирующем APK отсутствует INTERNET.

Сборки не содержат личных SQLite, серверного `data/`, токенов, ключей подписи и архивов переноса. README и runbook входят в Windows ZIP; исходные README сохранены отдельными историческими файлами.

## Что проверяет получатель

Установка на своём устройстве, удобство первого прохода FN01–FN06, разрешения уведомлений и малого окна Android, сигнал при блокировке/энергосбережении и ручной перенос между собственными устройствами. Проверка APK на физическом телефоне в рамках этого выпуска не выполнялась. Автоматическая синхронизация устройств не заявлена.
