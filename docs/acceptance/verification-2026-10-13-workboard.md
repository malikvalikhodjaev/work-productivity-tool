# Проверка 1.7.0 · Доска и пространство фокуса

Дата: 2026-10-13. Проверка агента на ПК; личная приёмка владельцем остаётся отдельным действием.

- **WB01:** создана работа со свободным описанием, следующим шагом, характером и направлением времени. Проверены доска и список; выбранный список сохранился после обновления страницы.
- **WB02:** в браузере изменено описание самостоятельной работы. Сохранность прежнего текста, пробелов, истории, заметок задачи проекта и отказ устаревшей вкладке дополнительно проверены Node-тестами.
- **WB03:** перевод в эксплуатацию без результата отклонён; с результатом сохранён. Выведенная стадия поддерживается моделью и фильтром; полный цикл вывода остаётся пунктом личной приёмки.
- **WB04:** запуск с карточки → пауза → обновление страницы → продолжение → завершение. История показала четыре действия и два рабочих интервала. В тесте браузера 56,722 секунды работы; разрыв между паузой и продолжением исключён. Node-тест повторяет запрос завершения и подтверждает одну запись факта.
- **WB05:** тестовый issue Coda взят в работу, исходная строка сохранена, кнопка повторного принятия отключена. Проверены таблицы карточек и четырёх событий таймера. Неполная строка импорта с неизвестными проектами/целями теперь даёт No Data и не блокирует остальные таблицы.
- **WB06:** с карточки задан пробный недельный норматив 0,5 часа; завершение её сеанса обновило связанный факт. Это тестовые данные отдельной установки, личный норматив владельца не менялся.
- **FA01–FA02:** проверены четыре темы и сохранение выбранной темы. Каждый из шести видов звука включился в Web Audio и показал состояние воспроизведения; громкость проверена на 5%. Звук выключен после проверки; после повторного открытия сам не запускается. Физический звуковой выход и качество звучания владелец оценивает отдельно.
- **FA03:** фокус-экран открывается и закрывается; в итоговом виде на ПК кнопки продолжения и учёта находятся в видимой области. При ширине 375 документ не переполняется: scrollWidth 360, innerWidth 375; доска прокручивается внутри блока, список помещается. Размер возвращён к обычному.
- **FA04:** устройство подготовлено, тестовый сервер выключен. После холодного открытия появились тема, отсчёт и управление звуком; коричневый шум воспроизводился без сервера. Запущен локальный сеанс по сохранённой работе, после паузы подтверждён пробный факт 1 секунда. Он остался в очереди и отправился после включения сервера: очередь 0, запись подтверждена сервером.
- **Код:** `npm run check` и 73 Node-теста прошли. Сетевые и файловые тесты выполнены вне ограничений песочницы, запрещавшей атомарную замену временных файлов. `.feature` не исполняются этим набором автоматически.
- **Рабочая установка:** health 1.7.0, доска существующих объектов, четыре темы, звук выключен. Перед обновлением сделана копия; хеши 16 рабочих JSON сохранились после установки и проверки. Прежний активный сеанс сохранился на паузе. Пробные карточки и факты остались в отдельном тестовом каталоге.

Это не проверка настоящего Android, звука при заблокированном экране или фактического входа Tailscale. Доска редактируется при доступном сервере; офлайн-сохранение предназначено для таймера устройства.
