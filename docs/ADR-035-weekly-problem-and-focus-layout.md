# ADR-035 Главная проблема недели и читаемый таймер

- Дата: 2026-10-24.
- Статус: принято для первой версии.
- Связано: ADR-003, ADR-022, ADR-034.

## Решение

В «Работе» есть отдельная запись «Главная проблема недели» с вопросом «The biggest problem of the week is…». Это выбор важного разрыва, который владелец хочет сократить за неделю. Выбор не подтверждает получение результата автоматически.

Неделя — понедельник–воскресенье по Ташкенту (UTC+5), ключ — дата понедельника. Новая неделя начинает с `No Data`; предыдущая формулировка не копируется. Можно выбрать прошлую сохранённую неделю и посмотреть или уточнить запись. Все заменённые формулировки сохраняются. Проблема дня и её связь с кейсом продолжают работать самостоятельно.

Сервер хранит `data/weekly-problems.json` и таблицу `weekly-problems.csv`. API: `GET/POST /api/weekly-problems`, native-модуль `weeklyProblem`, действие `save`. Изменение требует `expectedUpdatedAt`. Повтор UUID с прежними данными безопасен; чужая правка возвращает 409.

Windows и Android сначала атомарно записывают правку в локальную очередь SQLite. Локальная формулировка видна без сервера; синхронизация отправляет её при доступной связи. Квитанция содержит снимок недельных записей, поэтому подтверждённая запись не исчезает при последующей неудачной загрузке. Общий экран «Данные» и локальная выгрузка включают недельные записи и очередь.

В браузере текст сохраняется как черновик на этом устройстве; кнопка «Сохранить» записывает его на сервер. Это не фоновая очередь синхронизации native-приложений. При конфликте текст остаётся доступен для сравнения.

Цитата, присланная владельцем как референс Marc Andreessen, находится в личном реестре источников, вне публичного Git. Ссылка на первоисточник не предоставлена (`No Data`); авторство не считается проверенным. Подсказка с вопросами и референс свёрнуты по умолчанию.

## Размер окна таймера

Полный и малый плееры используют одну колонку шириной не более 560 логических пикселей, по центру широкого окна. При меньшей ширине колонка сужается; при недостатке высоты появляется явная вертикальная прокрутка. Название работы и текст проблемы переносятся без многоточия. «Пауза» и «Учесть» в полном плеере находятся перед чек-листом, чтобы длинный список нормативов не отодвигал управление вниз.

Невозможно уместить произвольное число нормативов и текст любой длины в маленькое окно одновременно с читаемым таймером. Прокрутка сохраняет доступ ко всему содержимому. Геометрия основного окна, закрепление и активный сеанс от смены представления не меняются.

## Проверка

Изолированные тесты проверяют границы недель, сырые тексты, историю, конфликты, повтор команд после потери ответа, отказ записи, HTTP-маршруты, локальную очередь и квитанцию. Widget-проверки: история недель, свёрнутый референс, окно 1840×900 и 430×330, доступ к кнопкам и последнему нормативу прокруткой. Наличие процесса Windows не заменяет проверку появления интерфейса.
