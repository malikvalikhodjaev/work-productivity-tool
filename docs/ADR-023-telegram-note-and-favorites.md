# ADR-023 · Telegram-заметки, обработка и избранное

Дата: 2026-10-16. Статус: принято по запросу владельца.

1. Название новой входящей записи — **`telegram-note (ДД.ММ.ГГГГ ЧЧ:ММ)`**, по времени отправки Asia/Tashkent. Полное сообщение, включая переводы строк, находится в многострочном поле **«Заметка»** (`body`). Его можно редактировать. «Мои мысли при разборе» остаются отдельным полем.
2. Исходное Telegram-сообщение и все update сохраняются отдельно от правок. Старые автоматически названные записи отображаются по новому правилу без перезаписи сырого архива. Ручные названия и разбор сохраняются. Правка сообщения в Telegram не заменяет отредактированное тело.
3. **«Обработал · в архив»** сохраняет текущие поля и переносит входящую мысль в обратимый архив. Переход виден сразу на устройстве, включая работу без сети. Пока команда не отправлялась, её правки можно объединять; отправленную команду менять нельзя. «Вернуть» возвращает входящую мысль.
4. У эссе и входящих есть метка **«Избранное»** и отдельный фильтр. Метка сохраняется локально, в очереди и на сервере. Архивирование входящей и удаление эссе в корзину не стирают звезду; корзина исключена из списка избранных эссе до восстановления. Метка не является публикацией, не добавляет результат или часы, не удваивает месячные счётчики.
5. Форматированный текст эссе остаётся Quill Delta. При изменении метки сохраняется последний текст редактора. Состояния черновика и личной публикации сохраняются; внешний блог и публикация в соцсетях не добавляются.

Приёмка: [NT01–NT03](acceptance/30-local-save-and-notes.feature). История и сырой источник остаются в личных данных; в Git публикуются только реализация и тестовые примеры.
