# Проверка веб-версии 1.20.0

Дата: 2026-10-19.

- 16 целевых тестов письма, передачи снимка и защищённого шлюза прошли. Проверены UUID маршрутов, сохранение ID и revision, исходные абзацы и форматирование, независимость копии документа в памяти, отказ при чужом архиве/ID. Прежние проверки автосохранения, конфликтов, локальных черновиков, истории, избранного и корзины включены.
- На отдельном локальном сервере с синтетическими заметками проверены: открытие существующей записи отдельной вкладкой, последние правки перед переходом, дописывание и сохранение, возврат к тому же ID, повторное открытие после перезагрузки, новая запись с немедленным переходом и прямое открытие пустого `/write`.
- На странице чистого листа видны только редактор, дата, тема, форматирование, сохранение, действия записи и свёрнутые подсказки. Навигация, входящие, список записей и таймер не загружаются. Открытие пустого листа не добавило запись в тестовый архив.
- Веб-сервер обновлён с резервной копией. Версия 1.20.0, маршрут `/write` отвечает; идентификаторы серверного сеанса таймера и архива письма сохранились. Личные заметки не заполнялись тестовым текстом, открытая вкладка владельца не перезагружалась.
- Это веб-изменение. Нативный Windows/Android клиент остаётся 0.1.16; новая сборка и перезапуск для этой поставки не выполнялись. Холодное открытие письма без сервера не проверялось и не обещается.
