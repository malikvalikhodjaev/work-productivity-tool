# ADR-053 · Чистая сетка, шкала и перенос ветвей индикаторов

Дата: 2026-10-27. Клиент 0.1.41+43, сервер 1.30.0. Продолжение ADR-051/052.

Владелец выбрал вариант 1 «Чистая сетка» со шкалой изменения из варианта 5. Индикаторы и недельные нормативы используют нейтральные ячейки, тонкие разделители и спокойное выделение строки в светлой и тёмной теме. Остальные разделы и выбранная тема приложения сохраняются. Высота короткой таблицы определяется содержимым; длинная таблица прокручивается. Увеличенный шрифт и многострочный редактор не ограничиваются прежней оценкой высоты строки.

По последующему уточнению владельца отдельная колонка «Изменение» убрана из таблицы. Если известны все значения, шкала находится в ячейке текущего значения. Шкала показывает исходное значение слева, предпочтительное справа и текущую позицию. Для уменьшаемой характеристики начало также слева, желаемое справа. Процент равен `(сейчас − начало) / (предпочтительное − начало)`. Он может быть отрицательным и превышать 100%; маркер ограничен краями. При неизвестных или совпадающих концах процент не выдумывается. Неизвестную шкалу можно записать; текущее значение открывает замер. Исходные факты не округляются и не заменяются.

## Перенос

Ручка у названия перетаскивает всю ветвь. Верхняя четверть строки вставляет перед ней, нижняя — после неё, середина вкладывает под неё. Перед/после использует родителя целевой строки, позволяя переходить между уровнями. Во время переноса над таблицей появляется зона «На верхний уровень». Место назначения подсвечивается. На Android перенос начинается долгим нажатием на ручку. Край таблицы запускает автоматическую прокрутку. Вложение раскрывает целевую ветвь.

При сортировке по значению столбца кнопка «Порядок строк» возвращает ручной порядок, сохраняя поиск, фильтры и настройки колонок. Перенос использует полное дерево, включая скрытые фильтром строки. Архив и корзина не восстанавливаются переносом. Циклы, перенос в себя, недоступный родитель и отсутствующее место вставки отклоняются.

## Данные

UUID и parentId задают связи, sortOrder — порядок соседей. Потомки, тексты, физическая система, свои ячейки и замеры сохраняются. WBS вычисляется заново. Команда moveGoal содержит ожидаемую структуру: ID, родителя, порядок и границы архива/корзины. Неизменяемая команда сначала пишется в SQLite. Сервер проверяет структуру и сохраняет перемещение с историей в одном workspace-файле; повтор requestId возвращает квитанцию. Изменение структуры на другом устройстве вызывает 409, исходное действие остаётся для разбора. Перепривязка к свежей структуре требует явного решения владельца.

Перенос не меняет updatedAt обычных полей. saveGoal отдельно проверяет expectedParentId, чтобы старый полный черновик не отменил перенос. Старый клиент без этого поля может сохранять строку только с текущим родителем. Объединение неотправленных обычных правок сохраняет исходного родителя команды, если перенос стоит после неё в очереди; проекция показывает новое положение. Незавершённые черновики не заслоняют серверный порядок.

Проверки включают порядок, перенос между уровнями, сохранность исходников и фактов, циклы, архив/корзину, устаревшую структуру, повтор команды и восстановление хранилища. Сборка и фактическая установка фиксируются отдельно в UI-WORKLOG.

Кнопка «＋ Столбец» находится рядом с поиском. Меню заголовка убирает свои колонки обратимым архивом с проверкой revision; значения сохраняются и синхронизируются. Стандартные колонки скрываются локально. «＋ Столбец» возвращает скрытые и архивные столбцы либо создаёт новый типизированный. Название индикатора остаётся доступным для иерархии. Внутренний ID delta сохраняется для совместимости, но не выводится отдельным столбцом.

На узком экране (менее 560 пикселей) первая колонка перестаёт быть закреплённой: вся таблица прокручивается горизонтально, название сохраняет читаемую ширину. На широком экране первая колонка остаётся закреплённой. Во время перетаскивания корневая зона появляется поверх панели поиска без сдвига строк под указателем.
