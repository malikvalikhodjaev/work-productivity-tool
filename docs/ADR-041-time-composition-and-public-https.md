# ADR-041 · Типы времени, паузы и HTTPS без VPN

Дата: 2026-10-25. Клиент 0.1.28. Уточняет ADR-030 и ADR-040 по запросу владельца.

## Учёт и аналитика

В «Работе» аналитика показывает часы, число полных рабочих помидорок и две независимые доли: от учтённого времени и от учтённых помидорок. Можно выбрать неделю или день этой недели. План, дневной лимит и 24 календарных часа не используются как знаменатель.

Типы: Investment, Productive, Leisure, Waste и «Без типа». Тип выбирается явно в карточке или при запуске активности и сохраняется в сеансе. Прежние произвольные значения сохраняются; неизвестное значение попадает в «Без типа». Изменение карточки не меняет прошлые сеансы. Промежутки без учёта не назначаются Waste. Жёсткие критерии Waste пока не согласованы; интерфейс даёт только рабочие ориентиры для ручной оценки.

Счётчик паузы выводится отдельно от замороженного рабочего отсчёта. Запущенный короткий/длинный перерыв показывает свой отсчёт и открывает плеер. Явные закрытые паузы восстанавливаются по событиям pause/leisure/resume/finish. Leisure и интервалы перерыва относятся к отдыху; обычная пауза остаётся «Без типа». Пересечение Leisure с паузой вычитается, интервалы делятся по полуночи Asia/Tashkent. Текущие незавершённые сеансы и отменённые/исключённые/конфликтующие локальные сеансы не добавляются как завершённый факт. Паузы и перерывы не создают рабочих помидорок.

## Android

Большой плеер использует вертикальную прокрутку всего содержимого. Чек-лист раскрыт полностью, без второго вертикального скролла внутри плеера или напоминания. Названия и кнопки переносятся на строки, размер текста не уменьшается для вмещения. При увеличенном системном шрифте часы допускают горизонтальную прокрутку. Настройки по-прежнему открываются отдельной кнопкой. Десктопный плеер сохраняет компактную компоновку.

## Доступ к собственному VPS без Tailscale

Владелец выбрал обычный HTTPS с временным доменом, позднее — своим. На VPS отдельный Caddy проверяет ключ владельца через HTTP Basic поверх HTTPS, затем обращается к прежнему закрытому шлюзу на loopback. Шлюз сохраняет проверки identity, Host, Origin и маршрутов; порты редактора наружу не публикуются. Запрос с посторонним Origin отклоняется до проксирования. Прежний путь Tailscale остаётся доступным для отката.

Клиент хранит ключ отдельно от адреса, привязав Authorization к точному origin. Межсерверные запросы и перенаправления отклоняются, проверка сертификата не отключается. Фон Android и загрузка голосовых используют тот же ключ. JSON-экспорт не содержит serverAuth. Сырые копии SQLite остаются приватными, поскольку могут содержать ключ.

Для обновления существующих устройств предусмотрен одноразовый `iw-connection.json` в собственном каталоге приложения. Приложение принимает его только при совпадении непустого serverId, проверяет HTTPS-origin и формат Authorization, атомарно меняет подключение и удаляет файл после успеха. База, очередь, исходные тексты и ID архива не сбрасываются. Ошибочный файл не применяется. Адреса, ключи и личные идентификаторы в исходники и сборочные assets не входят.

Один сервер остаётся архивом одного владельца. Это не реализация нескольких аккаунтов. После передачи устройства или раскрытия ключа его нужно заменить на сервере и клиентах.

## Иконка

Владелец выбрал коралловую помидорку с часами на округлённом квадрате для полного дашборда и Pomodoro Club. Название полного приложения, пакет Android, подпись и каталоги данных сохраняются.

## Проверки

Проверяются разные знаменатели, пустые данные, неизвестный тип, повторные снимки, пауза с Leisure через полночь, неизменность рабочего времени, область действия ключа, запрет перенаправлений и передачи ключа на иной origin, сохранность черновиков/очереди при смене подключения, Android 360×780 при масштабе шрифта 1 и 1,5 и минимальные размеры десктопного плеера.

Проверка реального подключения отдельно подтверждает TLS, отказ без ключа, отказ для постороннего Origin, запрет чтения сырых файлов и прежний ID архива. Готовая сборка и успешная проверка сервера не заменяют проверку синхронизации каждого установленного клиента.
